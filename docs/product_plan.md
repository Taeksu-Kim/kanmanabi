# korean_helper — 제품 기획 문서

> 기획자 관점 정리. 페인포인트 → 제품 테제 → 스코프 → 솔루션 방향.
> 상위 맥락은 [`project_overview.md`](./project_overview.md) 참조. 구체 기능·데이터모델·스택은 이후 문서에서.

## 1. 타깃 & 설명 원칙

- **타깃**: 한국어를 배우는 **일본인 학습자**, 입문~초급 (콘텐츠가 EP01~42 입문·초급 위주).
- **설명 원칙 (Japanese-first contrast)** — 서비스 전반(설명·문제 해설·오답 피드백·UI 카피)에 일관 적용:
  > 한국어 규칙을 단독으로 서술하지 않는다. 항상 일본어와 대조해 **같은 점 → 다른 점 → 함정** 순으로 일본인이 직관적으로 이해하도록 설명한다. 특히 "일본어 1개 → 한국어 여러 개"로 갈라지는 지점(조사·표현)은 역할 중심으로 짚는다.
  - 이는 신규 방침이 아니라 **기존 콘텐츠의 DNA를 명문화**한 것. (42/42 에피소드가 일본어 대조, 총 527회 언급 — `日本語との比較` / `日本語と発想が違う` 등 구조 자체가 대조)

## 2. 페인포인트 분석 (일본인 학습자, 개인 관점)

일본인 학습자는 문법·어순·조사·한자어가 한국어와 거의 1:1이라 초급을 빠르게 통과하는 **특수 케이스**. 그래서 고통이 영어권과 다르다.

- **A. "비슷해서 생기는 함정"** — 일본어 L1이 오히려 방해
  - 조사 미묘한 불일치(은/는 vs 이/가, に=에/에게/한테, で=에서/로), 한자어 거짓짝, 직역체
  - → 콘텐츠가 대조·교정 형태로 이미 다룸
- **B. "비슷함이 안 통하는 벽"** — 발음·듣기가 최대 장벽
  - 받침, 3중 자음 대립(평음/경음/격음), 모음 구별, 발음변화(철자≠소리), 불규칙 활용, 반말/존댓말 사회적 선택
  - 설명 부분은 콘텐츠가 다룸. **감각 훈련(reps)** 부분은 선형 영상이 원리적으로 못 함
- **C. "언어학습 보편 고통"** — 혼자 할 때 무너지는 지점
  - 망각 / 지속 실패 / 아웃풋 부재 / 자기 수준·다음 스텝 모름 / 피드백 부재 / 콘텐츠 파편화

## 3. 제품 테제

| | 담당 | 상태 |
|---|---|---|
| 정제된 **설명 + 순서(커리큘럼)** | 콘텐츠(kr_study_material, 42편) | ✅ 이미 강함 |
| 반복 훈련 + 능동 회상 + 기억 관리 **(reps)** | korean_helper 웹서비스 | ⬜ 우리가 얹을 것 |

웹서비스는 콘텐츠를 대체·중복하지 않는다. **이미 의도적으로 짜둔 EP 순서를 그대로 학습 경로(스킬트리)로 삼고**, 각 EP에 영상이 못 주는 **reps 엔진**(능동 풀이·즉시 채점·SRS 복습·진도 관리)을 붙이는 레이어다. PostgreSQL에 저장되는 진도·정답률·복습큐가 그 reps의 상태.

## 4. 스코프 결정

**범위 안 (초기 집중):** C층을 EP 커리큘럼 위에 reps 엔진으로 녹여내기.

**범위 밖:**
- **발음·듣기 감각 훈련 (B층)** — 의도된 구멍. 매체 특성상 지금 안 푼다. 추후 별도 콘텐츠로 다룰 여지만 남김.
- **실시간 회화, AI 작문 첨삭** — 초기 범위 밖.

## 5. C층 페인 → 솔루션 방향

각 방향은 **기존 EP 자산을 재활용**한다 (특히 콘텐츠에 이미 연습문제+정답이 난이도 ★☆☆~★★★로 존재).

| 페인 | 솔루션 방향 | 재활용 자산 |
|---|---|---|
| 망각 | SRS 복습 큐 — 문법포인트·예문을 카드화해 간격반복 | EP 예문/포인트 |
| 지속 실패 | 진도 가시화 · 스트릭 · 작은 성취. EP 순서 = 스킬트리 | video_plan 순서 |
| 아웃풋 부재 | 능동 풀이 — 기존 연습문제를 인터랙티브 채점, 빈칸·변환 드릴 | EP 연습문제/정답 |
| 자기 수준·다음 스텝 모름 | EP 순서 기반 학습 경로 + 현위치 표시 | video_plan 순서 |
| 피드백 부재 | 즉시 채점 + **일본어 대조 해설**(설명 원칙 적용) + 오답 리뷰 | EP 정답/해설 |
| 콘텐츠 파편화 | 영상 + 문법 + 문제 + 복습을 EP 단위 한 곳에 통합 | EP 전체 산출물 |

## 6. 레벨 & 지속성 방침

**온보딩 레벨 (자기평가)** — 시험 X (마찰·짜증). 가벼운 자기선택으로 시작점만 잡는다.
- **하나의 레벨 = `{ 우리 밴드 ↔ TOPIK 급수 ↔ 일본어 can-do 문장 }`**. can-do 문장을 고르면 TOPIK 급수·시작 EP가 동시에 정해짐 → TOPIK는 공용 눈금(호환 라벨), 실제 길은 EP 순서.
- can-do는 **모국어(일본어)에 앵커링**한 구체 문장으로 ("自己紹介や簡単な買い物ができる" 식). Japanese-first 원칙의 레벨판.
- 자기선택은 **초기 추측**일 뿐 — 실제 실력은 진도·정답률이 보정. 배치에 공들이지 말고 가볍게·스킵 가능하게. (선택적 미니 체크 3~5개 정도는 가능, 시험 아님)
- 콘텐츠 천장이 ≈TOPIK 1~2급이라 중급+ 자기선택자에겐 지금 줄 게 적음 → 레벨 선택이 콘텐츠 커버리지 구멍을 드러냄(→ Parking Lot).

**지속성 (habit)** — **소프트·격려 톤, 죄책감 유발 X, 목표는 러프하게.**
- 요일 고정 스케줄 ❌ (brittle — 하루 놓치면 전체가 무너짐). 대신 **러프한 빈도 목표**(주 N회 / 캐주얼·보통·집중) + **휴식일 있는 스트릭**(한 번 빠져도 리셋 X).
- **SRS due-큐가 일일 훅의 본체** — "오늘 복습할 카드 N장"이 매일 생겨 되돌아올 이유를 자동 생성. 명시적 목표·스트릭은 보조.
- 레벨과 같은 철학: 가벼운 초기값 → 실제 행동(관찰)이 보정.

## 8. 추후 검토 사항 (Parking Lot)

초기 범위 밖이지만 "안 다루는 것"이 아니라 **나중에 다룰** 항목. 필요 시 꺼내 쓴다.

- **발음·듣기 구멍 메우기 — 받아쓰기(dictation)**: 구간 오디오를 듣고 타이핑 → 정답 대조 채점. **임의 유튜브 링크가 아니라 우리 EP 오디오로** 시작하는 게 정답 — 오디오·SRT·정답 텍스트(`script_for_tts.md`)를 이미 인하우스로 보유해 저비용·저작권 클린. 임의 유튜브 버전(자막 수집·ASR·화자분리)은 ToS/컴퓨트/품질 짐이 많아 훨씬 후순위. YouTube IFrame API의 구간 반복(`seekTo`) 자체는 언제든 가벼운 부품으로 활용 가능.
- **회화문 콘텐츠 확충**: 이미 쇼츠로 만들어둔 자산 있음. 필요 시 재활용·확장 검토.
- **중급 이후 콘텐츠**: 현 콘텐츠는 초급(≈TOPIK 1~2급). 중급+ 학습자에게 유효한 콘텐츠는 별도 고민 필요 — 로드맵에 두되 지금은 초급 정조준.
- **동적 "현재 실력" 레벨**: MVP는 온보딩 시 정적 자기선택(can-do)로 시작점만 잡음. 진도·정답률로 레벨을 자동 갱신하고 "너 지금 여기"를 보여주는 동적 버전은 C층 "자기 수준 모름"을 더 잘 풀지만 설계가 무거워 다음 단계로 미룸.
- **관심사 기반 개인화**: 유저가 관심사(K-pop·드라마·요리·여행 등)를 설정하면 단어/예문을 그쪽으로 편향. 어휘 데이터가 정리된 뒤의 개인화 페이즈. 단어는 주제 태그로 필터(코어 어휘는 주제중립이라 제외), 예문은 **(관심사×단어) 오프라인 사전생성+검수 뱅크를 DB 서빙**(실시간 LLM 생성 X — 비용·레벨준수·품질). 관심사 설정은 가볍게·선택·변경가능. 착수 시 어휘 데이터에 주제/도메인 태그 자리 확보 필요.
