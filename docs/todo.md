### enrich 방식 결정 — 기초사전 파이프라인 채택 (2026-08-08)

참고 설계: `claude_korean_vocab_master_build.md` (2017 XLSX 백본 + 한국어기초사전 JP대역 JOIN → 단일 `korean_vocab_master.json` + `unmatched.json`).

- **채택 이유 = 품질·매칭 신뢰도** (라이선스 아님): ① 공식 전문 일본어 대역 ② 같은 기관·같은 동음이의어 번호 → `word+homonym_no+pos` 정밀 JOIN ③ 전체다운로드 1회 파싱, LLM은 갭·판별에만.
- **✅ 실측 검증(2026-08-08, krdict XML)**: 초급 등장 439단어 중 **일본어 대역 100%**, 한자(원어) 52%(한자어 부분집합에 정상). 전체 엔트리 기준 JP 95%·한자 65%. 동음이의어 분리 정확(가격[價格]→価格 vs 가격[加擊]→攻撃). 일본어 대역에 한자읽음 포함(価格→かかく【価格】).
- **소스 단일화 확정**: **일본어 뜻 + 한자 + 품사 + homonym_no가 krdict XML 한 파일에.** kaikki·영어판 Wiktionary(195MB) **불필요·드롭**(갭 fallback으로만). 미러: `github.com/spellcheck-ko/korean-dict-nikl-krdict` (11×~33MB, LMF DTD).
- **한자 필드**: `origin`(원어)에서 `hanja` 채움 (문서 스키마엔 없던 우리 차별점). JP 대역은 문서 지침대로 짧은 대표어 1~2개로 트림.
- ⚠️ **라이선스 정정(중요)**: 문서가 전제한 "기초사전=공공누리 1유형"은 **틀림.** 실제 배포 콘텐츠 = **CC BY-SA 2.0 KR** (GitHub 공식 미러 spellcheck-ko README 명시). → kaikki와 같은 share-alike 계열, **라이선스 이점 없음.**
  - 저작권 해법: ①SA준수 ②**권장: 기초사전을 사실 시드로만 쓰고 일본어 뜻을 우리 짧은 표현으로 재작성**(단어 대역·한자는 fact라 저작권 얇음). ⚠️**기초사전 예문은 벌크 사용 금지**(README상 "공정이용" 단서) — 예문은 2017 길잡이말+자체생성.
- kaikki 실측(아래)은 **JP 갭 규모 참고치·fallback**으로 유지.

### enrich 커버리지 실측 (2026-08-08, 초급 1,790단어 기준, kaikki 기준 참고치)

| 항목 | 자동 확보율 | 품질 | 소스(무료·CC-BY-SA) |
|---|---|---|---|
| **일본어 뜻** | **80%** (1,446), 정규화 시 ↑ | ✅ 깨끗 (녹색→緑色, 식당→飲食店、食堂) | 일본어판 Wiktionary `朝鮮語` (kaikki, 40k senses) |
| **한자 표기** | **39%** (711) = 한자어 부분집합에 정상 대응 | ✅ 깨끗 (수업→授業, 치료→治療) | 영어판 Wiktionary `Korean` (kaikki, 195MB) |
| EN 존재율 | 92% | — | 영어판 |

- 덤프 URL: JA=`kaikki.org/jawiktionary/朝鮮語/...jsonl`(16MB), EN=`kaikki.org/dictionary/Korean/kaikki.org-dictionary-Korean.jsonl`(195MB).
- **판정**: enrich **자동화 가능**. 일본어 뜻 80% 자동(무료) + 한자어 자동 한자 링크. 남는 부담 = JP뜻 15~20% 갭 + 정규화 클린업(합성어·동형어·`A/B`형)만 LLM/사전 보충. 백본+enrich 파이프라인 실현성 확인.
- ⚠️ 라이선스 판단: **백본(공공누리1유형)=문제없음.** **enrich(kaikki)=CC-BY-SA** → (1)출처표시 필수 (2)파생 뜻데이터셋은 SA 공개 가능성. 단 **SA는 콘텐츠/DB에만 적용, 앱 코드엔 전염 안 됨.** 한자매핑은 사실(fact)이라 리스크 낮음. **선택지**: ①SA준수(출처+파생SA공개, 단순) ②Wiktionary는 시드로만 쓰고 일본어뜻 LLM 재작성(SA노출 축소, 권장) ③JP뜻 소스 교체. 상업화 확정 전 법적 확인 권장.
