# EP → 문법 맵 (문법 문제 생성 backbone)

> 각 EP가 가르치는 문법포인트와 **생성 타입**. EP 학습의 하위 항목으로 붙는 문법 연습을
> 이 맵 기준으로 생성한다. 문제는 `episode_id`에 연결, **레벨 1,2 어휘**만 사용.
> 설계 원칙·엔진 경계: [`question_generation.md`](./question_generation.md).

## 생성 타입

| 타입 | 대상 | 엔진 | luna 역할 | 검증 |
|---|---|---|---|---|
| **T1** 조사 형태 | 받침으로 형태 결정(이/가·을/를·(으)로…) | **로직만** | — | 로직 100% |
| **T2** 규칙 활용 | 활용·시제·관형형(어형·과거·경어…) | 로직뼈대 + **luna** | 불규칙·예문·해설 | 로직이 규칙분 재계산, 불규칙 spot-check |
| **T3** 의미·뉘앙스 | 의미 선택·회화 표현·종결 뉘앙스 | **luna 저작** | 문제+해설 | ⚠️ 로직 불가 → `needs_review` 플래그 |

> 원본 형태·예외는 생성 시 해당 `episode.md`에서 최종 확인. 아래는 제목 기반 v1 분류.

## 요약 · 순서

- **T1(로직만) 우선 착수**: EP01·03·04·11·24·26·28·31·34·43의 조사 형태 부분. 내가 만든 받침 드릴을 **EP별로 스코프**(해당 조사만)+episode_id 연결로 재구성.
- **T2(활용)**: EP08~21 중심. 로직으로 규칙 활용 뼈대 생성 → luna로 불규칙·예문·해설 → 로직 검증.
- **T3(의미/뉘앙스)**: 나머지 다수. **luna 저작 + needs_review**. 초기엔 소량·검수 위주.
- 전 문제 **레벨 1,2 어휘 풀**에서 대상어 선택, `episode_id` 연결, Japanese-first 해설 필수.
- EP07은 문법포인트가 아니라 복습 → 별도 유형(기존 어휘/조사 문제 묶음) 재활용.
