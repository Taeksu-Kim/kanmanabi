# Study mobile question — concept v1

Status: rejected. Clear but too cold, formal, and form-like for a frequently used
consumer learning product. Keep only the hierarchy learnings; do not implement it.

## Fixed input

- Mobile-first responsive web, primary viewport 390×844.
- Audience: beginner Japanese learners of Korean.
- Real product surface, not a marketing landing page.
- Both tap selection and typed recall remain available for every question.
- Japanese UI copy; Korean is the learning object.

## Visual direction

Clear, quiet daily-practice tool built around the modular geometry of Hangul
syllable blocks. True white / very pale cool gray, deep ink navy, and a restrained
cobalt accent. Modern Japanese/Korean sans-serif typography, open layout, minimal
shadow, and one-column touch controls. Friendly without becoming childish.

## Generation prompt

Create a high-fidelity portrait mobile product UI concept in a 390×844 proportion
for kanmanabi, a mobile-first responsive web service that helps beginner Japanese
learners actively recall Korean vocabulary through fast daily review. Design the
complete primary study-question screen, not a marketing landing page.

Use a quiet compact header with the wordmark at left and review count at right, a
subtle progress rail, one dominant open study area with a large readable prompt,
four full-width choices in one vertical column, an understated separation, a text
input, and a primary submit action. Keep the entire task visible without scrolling.
Make tap and typed recall feel equally valid. Use true white or pale cool gray,
deep ink navy, restrained cobalt, excellent Japanese/Korean sans-serif alignment,
controlled spacing, moderate corners, subtle borders, nearly no shadow, accessible
contrast, and 44px or larger touch targets. Derive one restrained signature motif
from the modular geometry of Hangul syllable blocks. Keep UI text and controls
code-native in implementation and make the design practical for React + Vite.

Avoid cream or beige, serif type, terracotta, black backgrounds, acid green,
newspaper styling, mascots, national clichés, bento grids, nested cards,
glassmorphism, neon, glow, decorative badges, fake metrics, header clutter, hero
copy, marketing calls to action, illustrations, and Duolingo imitation.

## Review notes

- Keep: clear prompt hierarchy, restrained four-cell brand mark, segmented progress,
  single-column tap targets, open white composition.
- Validate next: compactness on a real 390×844 browser viewport, input-focus/IME
  behavior, selected-answer treatment, and whether the brand motif is distinctive
