# kanmanabi 화면 구조

## 학습 트랙

### 단어 트랙

`1~6급 단어 목록 → 단어 문제 → 단어 SRS 복습`

- 레벨 기준: 2017 국제 통용 한국어 표준 교육과정 1~6급
- TOPIK은 온보딩에서 사용자의 자기평가를 돕는 호환 눈금으로만 표시한다.
- 단어 문제와 복습 카드는 EP 진도와 분리한다.

### 문법 트랙

`EP01~EP42 → 영상 → 일본어 대조 포인트 → EP 문법 문제 → 문법 SRS 복습`

- 실제 학습 순서는 기존 영상 EP 커리큘럼을 따른다.
- EP 문제는 단어 자동생성 문제와 별도로 저작·구체화한다.

## 공통 화면

- 홈: 오늘의 복습과 단어/문법 트랙 진입
- 온보딩: 닉네임, TOPIK 연계 일본어 can-do 자기선택
- 기록: 단어와 문법 진도를 구분해 요약
- 오늘의 복습: 한 세션에서 제공하더라도 각 문항의 `単語`/`文法` 출처를 명시
- 설정/프로필: 닉네임, 레벨, 학습 빈도 수정

## POC 이후

- 리더보드는 초기 사용자 규모와 학습 지속성 데이터를 확인한 뒤 검토한다.
- TOPIK 3급 이상 문법 콘텐츠는 현재 EP 범위 밖이므로 준비 중 상태로 안내한다.
