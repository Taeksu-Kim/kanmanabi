# kanmanabi 학습 구조와 내비게이션

> 백엔드 계약 전 UX 기준. 실제 API 필드명·응답 형식은 백엔드 정리 후 맞춘다.

## 1. 구조 원칙

1. 하단 주 내비게이션은 `ホーム / 学習 / 記録` 세 개만 사용한다.
2. `学習`은 단어와 문법을 선택하는 허브이며 그 자체가 별도 학습 트랙은 아니다.
3. 단어와 문법은 콘텐츠·진도·문제·복습 상태를 독립적으로 관리한다.
4. `今日の復習`은 두 트랙의 due 항목을 모으는 유일한 공통 진입점이다.
5. 한 세션에서 두 트랙을 섞더라도 모든 문항에 `単語` 또는 `文法` 출처를 표시한다.
6. 현재 콘텐츠가 없는 동작은 가짜로 활성화하지 않고 준비 중 또는 빈 상태로 안내한다.

## 2. 정보 구조

```text
ホーム
├─ 今日の復習
│  ├─ 単語の復習
│  └─ 文法の復習
├─ 文法のつづき
├─ 今日の新しい単語
└─ 設定

学習
├─ 単語トラック
│  ├─ 等級を選ぶ（標準教育課程 1~6級）
│  ├─ 単語帳
│  │  └─ 単語詳細
│  ├─ 新しい単語を学ぶ
│  └─ 単語復習
└─ 文法コース
   ├─ EP01~EP43
   ├─ EP詳細
   │  ├─ 動画で学ぶ
   │  ├─ 日本語との違いを読む
   │  └─ 文法練習
   └─ 文法復習

記録
├─ 今週の学習
├─ 単語の進み具合
└─ 文法コースの進み具合
```

## 3. 화면별 역할

### ホーム

- 목적: 사용자가 고민하지 않고 오늘 할 한 가지를 시작하게 한다.
- 최우선 CTA: `今日の復習をはじめる`.
- 복습이 없으면 `今日の新しい単語` 또는 `文法のつづき` 중 마지막 활동을 우선 추천한다.
- 단어와 문법의 상세 탐색은 홈에 넣지 않는다. 각 트랙의 현재 위치만 한 줄씩 보여준다.
- 설정은 우상단 아이콘으로 진입한다.

### 学習 허브

- 목적: 사용자가 단어와 문법 중 무엇을 공부할지 의식적으로 고른다.
- 상단에는 자기평가 레벨을 `TOPIK 1級相当`처럼 참고 정보로만 표시한다.
- 첫 영역 `単語トラック`: 현재 선택한 표준교육과정 등급, 새 단어 학습, 단어장 진입.
- 둘째 영역 `文法コース`: 현재 EP 위치, 이어보기, 전체 EP 경로 진입.
- 두 영역은 동일한 카드 복제물이 아니라, 단어는 가로 단어 샘플/등급 레일, 문법은 세로 EP 진행선으로 성격을 구분한다.
- 전체 화면에 주 CTA를 하나만 두지 않는다. 사용자가 트랙을 선택하는 화면이므로 트랙별 CTA를 하나씩 둔다.

### 単語トラック

- `1~6級`은 국제 통용 한국어 표준 교육과정의 등급이다.
- 단어장, 새 단어 문제, 단어 복습을 이 트랙 안에서 연결한다.
- TOPIK 라벨을 단어 데이터의 출처처럼 사용하지 않는다.

### 文法コース

- EP01~EP43의 기존 순서가 기본 학습 경로다.
- 각 EP는 `動画 → ポイント → 文法練習`의 세 단계로 표시한다.
- 단어 문제 수나 단어 진도를 EP 완료 조건에 포함하지 않는다.

### 記録

- 단어와 문법 결과를 나란히 보여주되 합산 점수 하나로 환원하지 않는다.
- POC에서는 주간 학습일, 푼 문제 수, 단어 등급, 현재 EP만 있으면 충분하다.

## 4. 권장 프론트 경로

> URL은 구현 시 변경 가능하지만 화면 소유권과 계층은 유지한다.

| 경로 | 화면 | 하단 탭 |
|---|---|---|
| `/` | 홈 | ホーム |
| `/learn` | 학습 허브 | 学習 |
| `/learn/vocabulary` | 단어장 | 学習 |
| `/learn/vocabulary/:wordId` | 단어 상세 | 学習 |
| `/learn/grammar` | EP 문법 코스 | 学習 |
| `/learn/grammar/:episodeNo` | EP 상세 | 学習 |
| `/study/vocabulary` | 단어 학습 세션 | 숨김 |
| `/study/grammar/:episodeNo` | EP 문법 문제 세션 | 숨김 |
| `/review` | 오늘의 혼합 복습 | 숨김 |
| `/records` | 학습 기록 | 記録 |
| `/settings` | 설정·프로필 | 없음 |
| `/onboarding/level` | 레벨 선택 | 없음 |

현재 `/study`는 API 연결이 안정된 단어 세션이다. 새 구조를 구현할 때 `/study/vocabulary`로 옮기고 `/study`는 호환 리다이렉트로 남긴다.

## 5. 핵심 이동 규칙

| 출발 | 동작 | 도착 |
|---|---|---|
| 홈 | 오늘의 복습 시작 | `/review` |
| 홈 | 문법 이어보기 | 현재 EP 상세 |
| 홈 | 새 단어 학습 | `/study/vocabulary` |
| 학습 허브 | 단어 학습 | `/study/vocabulary` |
| 학습 허브 | 단어장 보기 | `/learn/vocabulary` |
| 학습 허브 | 문법 이어보기 | 현재 EP 상세 |
| 학습 허브 | 코스 전체 보기 | `/learn/grammar` |
| EP 상세 | 영상/포인트 완료 후 문법 연습 | `/study/grammar/:episodeNo` |
| 학습 세션 완료 | 홈으로 | `/` |
| 학습 세션 완료 | 더 학습 | 원래 트랙의 다음 학습 |

브라우저 뒤로가기는 세션 중 답안을 잃게 만들 수 있으므로, 답안 제출 후에는 현재 피드백 상태를 유지하고 세션 이탈 시에만 확인을 검토한다. POC에서는 제출 전 로컬 답안을 저장하지 않는다.

## 6. 공통 상태 규칙

- **로딩**: 화면 골격을 유지하며 현재 트랙의 형태를 닮은 스켈레톤을 표시한다.
- **빈 복습**: `今日は復習する項目がありません`와 새 단어/문법 이어보기 선택을 제공한다.
- **미지원 트랙**: 데이터를 조작해 흉내 내지 않고 `準備中`과 가능한 다른 트랙을 안내한다.
- **오류**: 화면 전체를 내보내지 않고 해당 영역 안에서 재시도한다. 최초 화면 데이터 전체가 실패한 경우에만 전체 오류 상태를 쓴다.
- **완료**: 단어/문법 출처별 결과를 보여주며 다음 행동은 홈과 같은 트랙 계속하기 두 개만 둔다.

## 7. 문제 응답 방식

kanmanabi의 기본 학습 철학은 보기에서 고르는 인식보다 직접 떠올리는 능동 회상을 우선하는 것이다.

- 답을 직접 입력하는 주관식을 모든 지원 문항의 기본 응답 방식으로 둔다.
- 객관식 후보가 있는 문항도 처음에는 후보를 숨길 수 있다.
- 입력 영역 가까이에 `選択肢を見る` 토글을 두고 켜면 후보를 표시한다. 다시 끄면 숨긴다.
- 후보를 표시한 뒤에도 입력란은 유지한다. 후보를 누르면 해당 답을 선택하고, 직접 입력하면 입력값을 제출한다.
- 후보 표시 여부는 정답 판정에 영향을 주지 않는다. 향후 학습 분석에서는 `힌트 사용 여부`로 별도 기록할 수 있다.
- 최초 기본값은 `후보 숨김`을 권장한다. 사용자가 설정에서 `最初から選択肢を表示`를 켜면 다음 세션부터 후보 표시를 기본값으로 사용한다.
- 후보가 없는 순수 주관식 문항에는 토글을 노출하지 않는다.
- 후보를 펼치는 동작만으로 답을 제출하거나 오답 처리하지 않는다.

권장 일본어 카피:

- 숨김 상태: `選択肢を見る`
- 표시 상태: `選択肢を隠す`
- 입력 안내: `韓国語を入力`
- 사용 가이드: `しっかり覚えたい時は入力、迷った時は選択肢を表示`

## 8. 백엔드와 나중에 맞출 경계

이 문서에서는 다음 값의 존재만 요구하고 이름·형식은 정하지 않는다.

- 오늘의 단어/문법 복습 존재 여부와 개수
- 현재 단어 등급과 학습 위치
- 현재 EP와 EP 내부 단계
- 단어 및 문법 세션 완료 결과
- 단어/문법별 기록 요약
- 문항의 객관식 후보 존재 여부와 향후 힌트 사용 기록

백엔드 API가 정리되면 이 다섯 경계를 기준으로 실제 계약과 대조한다.
